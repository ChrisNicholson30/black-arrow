# Paths from upstream Codex that Black Arrow does not carry.
#
# Syntax is a small subset of .gitignore:
#   dir/          everything under a directory at the repository root
#   file          one file at the repository root
#   **/name       a file with that name at any depth
#   **/*.ext      files with that extension at any depth
#   !pattern      keep these after all; later lines win
#
# Nothing here is needed to build, test, or ship Black Arrow with Cargo. When
# upstream changes or adds a file that matches, `upstream_sync.py` removes it
# again, so pruning costs nothing at merge time. To bring something back,
# delete its line and restore the files with `git checkout upstream/main -- <path>`.
#
# After editing this file run:  scripts/blackarrow/upstream_sync.py prune
